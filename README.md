
# Виселица — игра на JavaScript

Виселица — браузерная игра на JavaScript, в которой игрок должен угадать случайно выбранное слово, вводя буквы русского алфавита.

Правильно угаданные буквы открываются в слове, а при ошибках постепенно появляется рисунок игрового персонажа.

Проект выполнен в рамках воркшопа «Разработка логики игры „Виселица“» Нетологии.

## Основные возможности

- Случайный выбор слова из готового словаря.
- Отображение скрытого слова.
- Обработка ввода букв с физической клавиатуры.
- Открытие всех вхождений правильно угаданной буквы.
- Учёт неправильных попыток.
- Отображение состояния букв на виртуальной клавиатуре.
- Постепенное изменение рисунка игрового персонажа при ошибках.
- Определение победы и запуск новой партии.

## Техническая реализация

### Хранение игрового состояния

Для хранения состояния игры используются следующие переменные:

```javascript
let answer = "";
let answerState = "";
let mistakesCount = 0;
let lettersState;
```

| Переменная | Назначение |
| --- | --- |
| `answer` | Загаданное слово |
| `answerState` | Текущее отображение угаданных и скрытых букв |
| `mistakesCount` | Количество неправильных попыток |
| `lettersState` | Состояние букв виртуальной клавиатуры |

При начале новой партии состояние сбрасывается, после чего выбирается новое слово.

### Случайный выбор слова

Функция `generateWord()` выбирает случайное слово из предоставленного словаря.

Для получения случайного индекса используется `Math.random()`.

После выбора слова создаётся его скрытое представление из символов `*`.

Количество символов соответствует длине загаданного слова.

### Обработка введённых букв

Функция `onKeyClick(letter)` получает выбранную букву и проверяет, присутствует ли она в загаданном слове.

При правильном вводе открываются все вхождения буквы.

При неправильном вводе увеличивается количество ошибок и обновляется рисунок игрового персонажа.

Для каждой буквы сохраняется информация о результате предыдущих попыток.

Повторный ввод уже отмеченной буквы не добавляет новую ошибку.

### Обновление интерфейса

После обработки введённой буквы игровая логика вызывает предоставленные функции:

```javascript
drawPerson(mistakesCount);
drawBoard(lettersState);
drawAnswerState(answerState);
```

Они отвечают за отображение игрового персонажа, виртуальной клавиатуры и текущего состояния загаданного слова.

### Определение победы

После обработки буквы игра сравнивает текущее открытое представление слова с загаданным словом.

Если все буквы открыты, вызывается предоставленная функция `winGame()`.

Она отображает сообщение о победе и запускает новую партию.

## Установка и запуск

Игра представляет собой статическую веб-страницу и не требует установки зависимостей.

**1. Клонируйте репозиторий**

```bash
git clone https://github.com/potykalov/hangmanGame.git
cd hangmanGame
```

**2. Откройте игру**

Откройте файл `index.html` в браузере.

[Открыть Виселицу](https://potykalov.github.io/hangmanGame/)

## Особенности текущей версии

- Ввод букв осуществляется с физической клавиатуры.
- Виртуальная клавиатура отображает состояние букв, но нажатия мышью на нарисованные буквы не обрабатываются.
- После седьмой ошибки рисунок завершается, но сообщение о поражении появляется при следующем вводе буквы.
- Для победы необходимо открыть все буквы загаданного слова.
- После сообщения о победе или поражении начинается новая партия.
- Сохранение результатов между запусками не предусмотрено.
