
# Виселица — игра на JavaScript

**Виселица (Hangman Game)** — браузерная игра, в которой нужно угадать случайно выбранное слово, вводя буквы русского алфавита.

Правильно угаданные буквы открываются в слове, а при ошибках на экране постепенно появляется рисунок игрового персонажа.

Проект выполнен индивидуально в рамках воркшопа **«Разработка логики игры „Виселица“»** по модулю «Основы программирования» Нетологии.

## О проекте

«Виселица» — учебный проект по разработке игровой логики на JavaScript.

В рамках воркшопа был предоставлен готовый интерфейс с отрисовкой на Canvas, набором слов, русским алфавитом и функциями для отображения состояния игры.

**Моя задача — реализовать логику выбора слова, запуска новой партии и обработки вводимых игроком букв**, используя предоставленные функции интерфейса.

В ходе работы реализовал случайный выбор слова, формирование его скрытого представления, проверку введённых букв, учёт ошибок, открытие угаданных букв и определение победы.

Основная самостоятельная реализация находится в файле [`logic.js`](logic.js).

## Мой вклад

### 1. Запуск новой партии

Реализовал функцию `startGame()`, которая:

- Сбрасывает количество ошибок.
- Получает начальное состояние клавиатуры.
- Обновляет отображение игрового персонажа и букв.
- Запускает выбор нового слова.

### 2. Выбор и скрытие слова

Реализовал функцию `generateWord()`.

- Добавил случайный выбор слова из готового словаря.
- Реализовал создание скрытого представления слова из символов `*`.
- Добавил отображение начального состояния загаданного слова.

### 3. Обработка ввода

Реализовал функцию `onKeyClick(letter)`, которая:

- Находит введённую букву в массиве состояния клавиатуры.
- Проверяет, присутствует ли буква в загаданном слове.
- Отмечает правильные и неправильные варианты.
- Увеличивает счётчик ошибок при вводе новой неверной буквы.
- Открывает все вхождения правильно угаданной буквы в слове.
- Обновляет отображение клавиатуры, слова и игрового персонажа.
- Проверяет, угадано ли слово полностью.

Повторный ввод уже отмеченной буквы не добавляет новую ошибку и не изменяет повторно состояние правильно угаданной буквы.

## Правила и управление

В начале партии игра случайным образом выбирает слово и отображает вместо его букв символы `*`.

Игрок вводит буквы **с физической клавиатуры**. Виртуальная клавиатура с буквами отображается на экране и показывает результат предыдущих попыток.

Если введённая буква есть в слове, открываются все её вхождения.

Если буквы нет, количество ошибок увеличивается и рисунок игрового персонажа дополняется новым элементом.

На виртуальной клавиатуре:

- Правильно угаданные буквы выделяются зелёным кругом.
- Неверно выбранные буквы перечёркиваются красным.

Когда слово угадано полностью, отображается сообщение о победе и начинается новая партия.

Для ручного перезапуска игры можно нажать `Enter` или `Escape`.

**Ограничение текущей версии:** после седьмой ошибки сообщение о поражении и начало новой партии происходят при следующем нажатии буквы.

## Техническая реализация

### Хранение состояния игры

В `logic.js` используются следующие переменные:

```javascript
let answer = "";
let answerState = "";
let mistakesCount = 0;
let lettersState;
```

| Переменная | Назначение |
| --- | --- |
| `answer` | Загаданное слово |
| `answerState` | Текущее отображение угаданных и скрытых букв |
| `mistakesCount` | Количество неверных попыток |
| `lettersState` | Состояние букв виртуальной клавиатуры |

Для получения исходного набора букв используется готовая функция `getDefaultKeyboard()`.

### Случайный выбор слова

Функция `generateWord()` выбирает случайный элемент из массива `dictionary`.

```javascript
function generateWord() {
  answer = dictionary[Math.floor(Math.random() * dictionary.length)];
  answerState = "*".repeat(answer.length);
  drawAnswerState(answerState);
}
```

Для получения случайного индекса используется `Math.random()`, а для создания скрытого представления слова — метод `repeat()`.

### Проверка введённой буквы

Функция `onKeyClick()` получает выбранную букву и ищет соответствующий объект в массиве `lettersState`.

Если буквы нет в слове и ранее она не была отмечена как неверная, увеличивается `mistakesCount`, а свойство `error` соответствующего объекта получает значение `true`.

Если буква присутствует в слове и ранее не была угадана, её объект получает свойство `success: true`.

Затем функция проходит по символам загаданного слова и открывает **все позиции**, в которых встречается введённая буква.

### Обновление отображения

После обработки буквы игровая логика вызывает готовые функции интерфейса:

```javascript
drawPerson(mistakesCount);
drawBoard(lettersState);
drawAnswerState(answerState);
```

Они обновляют рисунок игрового персонажа, состояние виртуальной клавиатуры и отображение загаданного слова.

### Определение победы

После обновления состояния игра сравнивает открытые буквы с загаданным словом:

```javascript
if (answerState === answer) {
  winGame();
}
```

Если строки совпадают, вызывается предоставленная функция `winGame()`, которая отображает сообщение о победе и запускает новую партию.

## Технические задачи и решения

### 1. Открытие всех вхождений угаданной буквы

**Задача**

Если буква встречается в слове несколько раз, необходимо открыть её во всех соответствующих позициях, сохранив ранее угаданные буквы.

**Решение**

Преобразовал текущее состояние слова в массив символов и прошёл по загаданному слову циклом.

При совпадении символа с введённой буквой заменил `*` в соответствующей позиции. После проверки всех символов собрал обновлённую строку с помощью `join()`.

**Результат**

При правильном вводе открываются все вхождения выбранной буквы, а ранее угаданные символы сохраняются.

### 2. Учёт повторного ввода букв

**Задача**

Повторное нажатие уже выбранной буквы не должно увеличивать количество ошибок или изменять результат предыдущей попытки.

**Решение**

Для каждой буквы используется объект состояния клавиатуры со свойствами `char`, `success` и `error`.

Перед изменением состояния проверяется, была ли соответствующая буква отмечена ранее.

**Результат**

Повторный ввод неверной буквы не увеличивает счётчик ошибок. Повторный ввод правильной буквы не запускает повторное открытие символов.

### 3. Сброс состояния перед новой партией

**Задача**

При запуске новой игры необходимо очистить результаты предыдущей партии: количество ошибок, отметки введённых букв и отображаемое слово.

**Решение**

В функции `startGame()` реализовал сброс счётчика ошибок и получение начального состояния клавиатуры.

После обновления интерфейса вызывается `generateWord()`, которая выбирает новое слово и формирует его скрытое представление.

**Результат**

Новая партия начинается с пустой истории попыток и заново сформированного состояния загаданного слова.

## Установка и запуск

Игра представляет собой статическую веб-страницу и не требует серверной части.

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/potykalov/hangmanGame.git
```

### 2. Перейдите в каталог проекта

```bash
cd hangmanGame
```

### 3. Откройте игру

Откройте файл `index.html` в браузере.

## Особенности текущей реализации

- Игрок вводит буквы с физической клавиатуры; нажатия мышью на нарисованные буквы не обрабатываются.
- После седьмой ошибки рисунок завершается, но сообщение о поражении появляется при следующем вводе буквы.
- Для победы необходимо открыть все буквы слова.
- После сообщения о победе или поражении начинается новая партия.
- Слово выбирается случайно из словаря; сохранение результатов между запусками не предусмотрено.
